# romantic-calc
A web-based calculator focused on speed and simplicity, with the ability to show Roman Numerals.

### Installation and Usage
- Download or clone, then run `npm i`
- Run `npm run emit-types-for-roman` (so that types will be generated for the old roman-js library)
- Run `npm start` (it should auto-open your default browser once built)

Click the Roman 'V' to switch to Roman Numeral display mode, and click on '123' to switch back to standard Arabic numerals.

### NOTE
This is very much early-alpha software, lots of cases were written for, BUT a lot of debugging and fixing is still need to be done in the future.
